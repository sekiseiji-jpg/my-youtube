# MY Youtube

好みの単語（マイワード）を保存しておき、**クリックで組み合わせて YouTube を検索 → 一覧から選んでその場で視聴**するためのWebアプリです。
PC・Android・iPhone のどれでも使えます。インストール不要・ビルド不要、HTML / CSS / JavaScript のみでライブラリは一切使っていません。

## 起動（PC）

`serve.cmd` をダブルクリックすると、ローカルサーバーが起動してブラウザが開きます。

```
======================================================
  MY Youtube  -  サーバーを起動しました
======================================================
  このPC          :  http://localhost:8787/
  スマホ・タブレット:  http://192.168.1.23:8787/
```

ウィンドウを閉じる（または `Ctrl+C`）で停止します。初回だけ **APIキーの設定** が必要です（下記）。

## スマホ（Android / iPhone）で見る

1. PCで `serve.cmd` を起動したままにする
2. スマホを**PCと同じWi-Fi**につなぐ
3. 画面に出ている `http://192.168.x.x:8787/` をスマホのブラウザに入力する

初回は Windows のファイアウォール確認が出ることがあります。**「プライベート ネットワーク」を許可**してください。

### ホーム画面に追加（アプリのように使う）

- **iPhone**：Safari で開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー → 「ホーム画面に追加」

アドレスバーのない全画面で起動します。
※ オフライン起動（Service Worker）は `https://` または `localhost` でのみ有効です。LAN経由の `http://192.168.x.x` では無効になりますが、アプリの動作自体に影響はありません。

### 外出先から使う（公開済み）

上記のLAN経由は「PCの電源が入っていて同じWi-Fiにいる」ことが前提です。
外出先用に GitHub Pages で公開してあります。PCを起動していなくても、どこからでもこのURLで使えます。

### スマホでの操作

| 操作 | 内容 |
|---|---|
| 左上の ☰ ／ 右下の「ワード」ボタン | マイワードのパネルを開く |
| ワードをタップ | 検索条件に追加（AND） |
| ワードを**長押し** | そのワードを**除外**（PCの Shift+クリックと同じ） |
| パネル下の「この条件で検索」 | パネルを閉じて検索 |
| 「絞り込み ▾」 | 並び順・長さ・期間などの条件を開く |

再生中はプレーヤーが画面上部に固定されるので、下の一覧をスクロールしながら次の動画を選べます。

## APIキーの取得（無料・初回のみ）

1. [Google Cloud コンソール](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→ ライブラリ →「**YouTube Data API v3**」を有効化
3. 「認証情報」→「**APIキーを作成**」してコピー
4. アプリ右上の **⚙ 設定** に貼り付けて「保存」（「接続テスト」で確認できます）

キーはブラウザの localStorage にのみ保存され、YouTube API へのリクエスト以外に送信されることはありません。
キーに「アプリケーションの制限」をかける場合は、HTTPリファラーに `http://localhost:8787/*` と `http://192.168.*.*:8787/*` を許可してください（制限なしでも可）。
スマホとPCは別々のブラウザなので、**スマホ側でも一度APIキーの入力が必要**です。

### 無料枠について

- 1日 **10,000 ユニット**／検索1回 = 100ユニット + 動画詳細1ユニット → **1日およそ100回**の検索が可能
- 同じ条件での再検索は **30分間キャッシュ**され、ユニットを消費しません（`↻ 再取得` で強制的に取り直せます）
- 右上に本日の推定消費量が表示されます（PCとスマホで別々にカウントされます）

## 使い方

| 操作 | 内容 |
|---|---|
| 左下の入力欄 + `＋` | マイワードを追加。`作業用BGM, ジャズ, 1時間` のようにカンマ区切りで一括追加できます。「グループ」を入れると分類されます |
| ワードをクリック | 検索条件に**追加**（AND 結合） |
| `Shift` + クリック（スマホは長押し） | そのワードを**除外**（クエリでは `-ワード`） |
| 「結合」を OR に | 選択したワードの**どれかを含む**検索（`(A \| B \| C)`） |
| 上の入力欄 | その場限りの追加キーワード。`Enter` で検索 |
| 「編集」ボタン | ワードの ✎ 名前変更 / × 削除を表示 |
| 「今の条件を保存」 | 選択ワード + 絞り込み条件をまとめて保存。次回はクリック1回で同じ検索 |
| サムネイル / タイトル | その場で再生 |
| `＋ キュー` | 再生キューに追加。「連続再生」オンで自動的に次の動画へ |
| `♡` | お気に入り登録（サイドバーにいつでも残ります） |
| 検索履歴の `★` | その検索条件を「組み合わせ」として保存 |

絞り込みは **並び順 / 動画の長さ / 公開期間 / 件数 / 高画質のみ / 字幕あり / 日本語優先** に対応しています。

### ショートカット（PC）

- `/` … 検索欄へ移動
- `Enter` … 検索（検索欄にフォーカス中）
- `Esc` … ダイアログ／プレーヤーを閉じる

## データの保存と引っ越し

マイワード・組み合わせ・お気に入り・キュー・検索履歴・APIキーはすべて**その端末のブラウザ**の localStorage に保存されます（サーバーには何も送りません）。
PCとスマホの間で同じワードを使いたいときは、**⚙ 設定 → 書き出し (JSON)** でファイルを保存し、もう一方の端末で **読み込み (JSON)** してください。

## ファイル構成

```
index.html              画面の構造
styles.css              スタイル（ダークテーマ・スマホ対応）
app.js                  ワード管理・検索・プレーヤー制御
manifest.webmanifest    ホーム画面に追加したときのアプリ情報
sw.js                   Service Worker（オフライン起動用）
icons/                  アプリアイコン (180/192/512px)
serve.py                ローカルサーバー本体（LANのURLを表示する）
serve.cmd               serve.py を起動するショートカット
```

## 注意点

- 動画の所有者が埋め込み再生を許可していない場合はアプリ内で再生できません。その動画には「※ 埋め込み再生が制限された動画です」と表示されるので、`YouTube` リンクから視聴してください。
- 再生は YouTube の公式埋め込みプレーヤー（IFrame Player API）を使用しています。動画のダウンロード機能はありません。
- iPhone では、動画はページ内で再生されます（`playsinline`）。全画面にしたいときはプレーヤー右下のボタンを使ってください。
